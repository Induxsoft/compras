# Compras.
El paquete Compras de V12 es el módulo que gestiona todas las operaciones relacionadas con la adquisición de productos, utilizando documentos comerciales y flujos de operación para mantener un control ordenado y transparente del proceso de abastecimiento.

## Manual del usuario

El manual de usuario está disponible aquí: <https://docs.induxsoft.net/es/productos/v12/users/compras/>

## Código fuente

Todo el código está disponible en la carpeta [https://github.com/Induxsoft/compras/tree/main/src)
